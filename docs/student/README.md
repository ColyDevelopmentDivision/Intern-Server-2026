# インターン参加者向け 環境構築ガイド

Coly 2026年度 1day インターンにご参加のみなさん、こんにちは！

このドキュメントは、インターン当日の課題に取り組むために、あなたの PC に開発環境を準備するための手順書です。

**プログラミングが初めての方でも読めるように書いています。** 分からない用語が出てきたら、まずは §02 の「用語とツールの基礎知識」を読んでみてください。

> 💡 本ガイドは **PDF形式** と **オンライン版（Markdown）** の両方で配布されます。内容は同じなので、お好みの形式で進めてください。PDFには Windows / Mac 両方の環境構築章（§03 / §04）が含まれているので、**ご自身のOSの章だけ**を読んでください。

## 何をインストールするの？

インターンで使うツールは以下です。詳しくは §03 / §04 で説明します。

| ツール | 何をするもの？ | セットアップ手段 |
|-------|--------------|-----------------|
| **SourceTree** | **リポジトリ**（プロジェクトのソースコードと変更履歴をまとめて管理する入れ物）を取得・管理する GUI ツール | **別途配布のセットアップマニュアル**を参照。まだ入っていない方は [§07 付録](./07-付録-SourceTree.md) も参考にできます |
| Docker Desktop | データベース（MySQL）を簡単に動かす道具 | 本ガイド §03 / §04 |
| .NET 10 SDK | 「API」というプログラムを動かす道具 | 本ガイド §03 / §04 |
| Visual Studio Code | ソースコードを書いたり動かしたりするエディタ（メモ帳の高機能版） | 本ガイド §03 / §04 |

## 進め方の目安

1. まず §01（はじめに）で全体像を掴む
2. §02（用語とツール）でよく出てくる言葉を確認する
3. お使いのOSに合わせて §03 か §04 を進める
4. §05 で「Hello World」を動かして動作確認する
5. 動いたら準備完了！インターン当日をお楽しみにしていてください。

> 💡 **この手順書のスコープ**: **インターン当日までにあなたのPC側で済ませておく事前準備**を扱います。実際のインターン用リポジトリのクローンや動作は **当日のプログラム** で行います。

---

## 困ったときは

- 手順の途中でエラーが出たら → **§06 トラブルシューティング** を確認
- それでも解決しない場合でも大丈夫 → **インターン当日は早めに来てスタッフと一緒にセットアップする時間**を設けています
