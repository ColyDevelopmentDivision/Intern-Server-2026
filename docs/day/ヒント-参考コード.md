# ヒント: 参考コード

`Users/` 配下のコードは、Service 層と Controller（1エンドポイント1ファイル構造）の**リファレンス実装**として使えます。以下のパターンが揃っています。

| 使いたい場面 | 参考コード |
|---|---|
| **DBにデータを保存したい時** | `UserService.CreateAsync`（`ExecuteAsync` で `INSERT ... VALUES (@name)`） |
| **複数のDB操作をまとめて成功／失敗させたい時**（片方だけ成功して片方失敗、を防ぐ） | `UserService.CreateAsync`（`BeginTransactionAsync` + `Commit`） |
| **DBの重複エラー（例: 同じ名前のユーザーを2人作れない）を検知したい時** | `UserService.CreateAsync`（`MySqlException.Number == 1062` の UNIQUE 制約違反ハンドリング） |
| **DBを検索して「見つからないかも」な結果を扱いたい時** | `UserService.LoginAsync`（nullable 型で受ける） |
| **クライアントから送られてきたリクエストが正しいか確認したい時** | `Users/UserCreateController.cs`（`IsNullOrWhiteSpace` → `BadRequest`） |

**Swagger からも試せます**:
- `POST /api/user/create` に Body `{ "name": "Dave" }` を投げると新規ユーザーが作られ、`{ "userId": 4, "name": "Dave" }` が返ります (初期所持品として魔石 300 が同時に付与されます)
- `POST /api/user/login` に Body `{ "name": "Alice" }` を投げると既存ユーザーの userId が引けます
