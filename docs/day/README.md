## 詰まった時は

> 💡 動作確認ツール (Unity / Swagger / phpMyAdmin) の使い方は、[動作確認マニュアル](./動作確認マニュアル.md) にまとまっています。
> 💡 追加課題で書き方に迷ったら、[ヒント: 参考コード](./ヒント-参考コード.md) を見てみてください。`Users/` 配下のコードが見本になります。

### エラーで動かない場合

1. エラーメッセージを AI や Google で検索する
2. 期待入出力と、実際の Swagger の Response を比較する
3. `docker compose ps` で MySQL が起動しているか確認、phpMyAdmin で DB の中身を見る
4. 該当課題ドキュメントの「ヒント」節を読み返す

### 何をすればいいかわからない場合

1. 該当課題のドキュメント (`docs/day/challenges/...`) を頭から読み直す
2. 実装計画書に戻って「どんな機能を実現するか」「AI に何を聞くか」を整理し直す
3. [ヒント: 参考コード](./ヒント-参考コード.md) の `Users/` 配下を眺めて、書き方の見本を探す

### それでも解決しない時

- **周りの参加学生に相談** → 状況を言葉にすることで解決の糸口が見えることもあります
- **AI やスタッフ**に以下を伝える:
    - どの課題を書いているか (課題番号)
    - 何を試したか
    - どんなエラーが出ているか (スクショか全文)
