# 第1部: 書き方の例（カード育成）

## 例: レベルを上げる

### 何を作る？

リクエストされたカードIDを用いて、ユーザーのカードデータのレベルを更新する。

### なぜ必要？

レベルがサーバーに保存されないと、アプリを閉じた時に育成した結果が消えてしまう。カード育成機能の土台になる処理。

### 処理の手順

1. リクエストからカードIDを受け取る
2. DB からそのユーザーのカードデータを取得する
3. 取得したレベルに 1 を足す
4. DB に書き戻す
5. 更新後のレベルをレスポンスで返す

### AIに聞いたこと

- 質問: C# のメソッド名や変数名は、大文字で始めるのか小文字で始めるのか？
- 回答: メソッド名は大文字始まり（`LevelUp`）、ローカル変数や引数は小文字始まり（`cardId`）が慣例。既存コードもそうなっているので合わせた。

### 書き方の候補と、選んだ理由

- 候補A: メソッド名を `UpdateLevel` にする
- 候補B: メソッド名を `LevelUp` にする
- **採用: 候補B**。このメソッドは「レベルを 1 上げる」以外のことはしないので、`Update` より `LevelUp` の方が、あとで読んだ人に何をするか伝わりやすいから。

### 結果確認

APIを実行後、DBでカードのレベルが1増えていることを確認した。

### 詰まったこと・気付いたこと（任意）

- Swagger で叩いたら 400 エラーが返ってきて焦ったが、Body の JSON で `"cardId"` と書くべきところを `"cardID"` と書いていただけだった
- 変数名を `lv` と略していたら、10 分後に自分でも何の値か分からなくなったので `level` に直した
- AI に「このエラーどう直す？」とだけ聞いていたが、エラーメッセージを丸ごと貼った方が的確な答えが返ってくると気づいた
