# 発展課題 (時間が余った人向け)

- **テストを考える**: 追加課題A〜Dで作った機能 (`HasEnoughAsync` / `ConsumeAsync` / `GrantAsync` / 履歴ベース `isNew` 判定) を、「バグに気づくためのテスト」で守る。それぞれについて「どの入力で、どの期待出力を検証するか (正常系・境界値・異常系)」を洗い出し、xUnit / NUnit などのテストフレームワークで自動化します
- **確率検証**: `POST /api/debug/gacha-draw-one?gachaId=1` を1万回叩くツールを書き、排出率を集計します
- **10連1枚以上SR確定**: `GachaService.DrawManyAsync` を改造。全部R以下だったら1枚をSR以上に差し替えます
- **ガチャ履歴テーブル**: `user_gacha_history` を追加して、いつ何を引いたかを保存します
- **同時実行制御**: 連打された時のレースコンディションを SELECT ... FOR UPDATE で防ぎます
- **トランザクション**: Consume + Grant を1つのトランザクションに包みます
- **開催期間チェック**: `gacha_master.start_at` / `end_at` を見て、期間外のガチャは 400 BadRequest で拒否します

詳しくはスタッフに質問してください。
